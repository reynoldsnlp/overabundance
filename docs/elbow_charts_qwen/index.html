K-means elbow / silhouette analysis

One PNG per optimal-k bucket. Each subplot shows silhouette vs k for a single lexeme×mps system; the red dashed line marks the optimal k (argmax silhouette). Source: run_elbow_analysis.py on head_embed_cache_Qwen_Qwen2.5-32B.jsonl (k ∈ [2,10]).

The all bucket uses every token; the no_cond, prob, and cat buckets restrict to tokens whose meaning is labelled with that cond_type in conditioning_by_meaning.csv.
